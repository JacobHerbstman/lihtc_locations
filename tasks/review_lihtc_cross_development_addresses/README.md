# Review LIHTC Cross-Development Addresses

This task validates the committed two-pass review of the 137 highest-evidence
identity questions created from addresses shared by different developments.
The questions contain 279 current physical-development records.

The review merges 113 questions and retains 24 as separate developments.
Retained questions include real phases or components, distinct properties on a
common campus, portfolio-financing overlaps, street-only placeholders, and
cross-listed source addresses. No decision approves a geocoding query or edits
a source row.

Run from `code/`:

```sh
make
```
