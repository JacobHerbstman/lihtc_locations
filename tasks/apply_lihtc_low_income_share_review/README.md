# Apply low-income-share review

This task applies only project-scoped low-income-unit decisions from the
validated Wisconsin and other-state review ledgers. It does not rewrite any
financing-episode source value.

The final physical-development low-income count is replaced for 176 reviewed
developments. Eleven documented nominal 20-percent set-asides retain their
integer counts even though rounding places them just below 20 percent. Eighty-
eight unresolved records retain their frozen values for provenance but are
explicitly ineligible for low-income-share analysis. Developments with
incomplete total or low-income counts remain ineligible under a separate
status.

The development, episode, and site keys and row counts are preserved. The
episode and site outputs carry the reviewed physical-development value and
analysis status; raw episode fields remain immutable.
