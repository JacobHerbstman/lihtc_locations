# Review LIHTC Name-Variant Linkage

This task validates the second committed linkage ledger. It covers all 163 current same-state-ID, same-standardized-primary-address blocks whose normalized names differ.

The ledger records a HUD-only read and a separate outside-source read for every block. It merges 154 blocks and retains nine as separate physical developments. The nine retained blocks contain separately named phases, components, or projects with distinct unit scopes; they remain documented address/state-ID collisions.

Run from `code/`:

```sh
make
```
