# Review protocol

Each identity decision uses two reads: the current HUD episode and full site
lineage, followed by a direct outside source. A physical merge requires the
outside source to identify one built property or community. A shared financing
name, state identifier, or copied address set is not enough.

Every site carried by a reviewed member receives its own decision. A
`keep_verified_physical_site` action requires the outside citation to support
that exact address or site, not merely the development identity. A physical
site whose individual address is not outside-verified remains retained with
`retain_unresolved_source_site_for_review`; it is not approved for geocoding.
Financing-portfolio sites remain explicitly nonphysical. Wrong-property sites,
malformed redundant variants, and reviewed historical address aliases are
removed only through a frozen site action.

Every HUD episode is retained. Unit counts are not summed or inferred during
identity review; newly merged rows return to unit-scope adjudication.
