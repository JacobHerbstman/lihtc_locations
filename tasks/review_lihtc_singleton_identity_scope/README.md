# Review singleton identity and scope corrections

This task freezes the outside review of identity and site-scope problems found
after the mixed-site application. The member ledger distinguishes physical
development merges from financing portfolios and invalid source rows. The site
ledger separately decides whether every source site is retained or removed. An
exact site is called verified only when its outside citation supports that
address; development-level evidence alone leaves the site retained but
unresolved. A separate one-row transaction ledger adds the official address
for a reviewed source record whose HUD row has no physical site at all.

No geocoding query is approved here, and no unit count is adjudicated.

The operative hierarchy is:

- one physical-development row for one documented property or community,
  including a multi-building or multisite development when an outside source
  treats it as one development;
- one project-episode row for each financing or phase record; and
- one development-site row for each individual physical address, building, or
  lot represented in the source inventory.

A financing portfolio that spans separately named properties is not a physical
development. It remains a nonphysical row that requires a property bridge.
