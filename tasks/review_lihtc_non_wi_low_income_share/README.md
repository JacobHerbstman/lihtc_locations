# Non-Wisconsin low-income-share review

This task records the two-reader adjudication of every non-Wisconsin physical development whose frozen LIHTC low-income-unit share is below 20 percent. It does not change the analytical data. The next application task may use only `replace_low_income_units` decisions with a project-scoped external count.

`code/nonwi_low_income_share_review.csv` is the hand-reviewed ledger. A row with no project-scoped count is deliberately unresolved; the frozen count remains available but is not affirmed by this review.
