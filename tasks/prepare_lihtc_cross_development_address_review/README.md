# Prepare LIHTC Cross-Development Address Review

This task turns the high-identity-evidence edges from the shared-address audit
into connected review questions. A question may contain more than two
developments, so it is reviewed once rather than as inconsistent pairwise
decisions.

The task carries forward prior `retain_separate` decisions and their outside
sources. New questions receive an internal evidence pattern only. It does not
merge developments, change addresses, approve geocoding queries, or make a new
identity decision.

Run from `code/`:

```sh
make
```
