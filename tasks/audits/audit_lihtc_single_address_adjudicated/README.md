# Audit Applied LIHTC Single-Address Review

This audit independently verifies that the committed single-address member
partition was applied exactly once to every reviewed development. It checks
development lineage, project-episode preservation, protected episode fields,
site-key reconciliation, contributing HUD identifiers, unit-review safeguards,
and the prohibition on approved geocoding queries.

The audit does not change an identity decision, resolve unit totals, repair an
address, or call a geocoder.

Run `make` from `code/`.
