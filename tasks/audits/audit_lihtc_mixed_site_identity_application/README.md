# Audit LIHTC Mixed-Site Identity Application

This independent audit verifies that the committed mixed-site partition was
applied after source-site repair without losing episodes, inventing site keys,
or inferring development-level unit totals. It separately verifies two source
financing umbrellas, ten source portfolio placeholders, and the 340-unit
Hobbs/Ciena financing umbrella added by this review. Those 13 rows are
excluded from the 53,927-row physical-development count.
