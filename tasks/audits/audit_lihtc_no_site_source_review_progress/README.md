# Audit LIHTC No-Site Source-Review Progress

This audit gives every one of the 797 physical developments with no retained
site a single current source-review route. It combines only preparation and
review outputs; it does not add, accept, or geocode a site.

Pennsylvania and Texas distinguish the small second-read subsets from rows
that received only an allocating-agency screen. North Carolina and Maine have
official first-source screens but no accepted address evidence. Georgia and
Indiana are explicit source-access blockers because the required official
feature rows or workbook bytes are not frozen. All other states remain in the
`no_state_source_task` route.

Every row remains unadjudicated and geocoding-unapproved. The progress table
is an acceptance-work inventory, not evidence that any no-site development is
located. Run `make` from `code/`.
