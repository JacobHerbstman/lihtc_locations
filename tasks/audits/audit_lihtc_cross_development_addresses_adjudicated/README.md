# Audit Adjudicated LIHTC Cross-Development Addresses

This task repeats the shared-address audit after applying the committed
physical-development identity decisions. It maps the original local readiness
evidence to the adjudicated development IDs, collapses exact development-site
keys, and rebuilds address groups and unique development pairs.

Previously retained development questions are identified separately from new
unresolved pairs. The audit does not edit a source address, change an identity,
approve a query, or call a geocoder.

Run from `code/`:

```sh
make
```
