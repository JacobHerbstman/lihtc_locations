# Audit Adjudicated LIHTC Identical Address Sets

This task verifies application of the committed identical multi-address-set
review. It checks the physical-development assignment, preservation of every
HUD project episode, development/site key uniqueness, exact site-key
reconciliation, unit-review safeguards, and the unchanged status of the two
excluded portfolio cross-listings.

The audit does not change an identity decision, repair an address, aggregate
unit totals, or approve a geocoding query.

Run `make` from `code/`.
