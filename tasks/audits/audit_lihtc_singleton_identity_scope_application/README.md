# Audit singleton identity and scope application

This audit independently verifies the reviewed development mapping, episode
preservation, physical and nonphysical scope statuses, reviewed name changes,
and site keep/drop contract. A site row may disappear only when the frozen site
ledger contains an explicit drop action or when retained rows share one final
site key and their complete source lineage is collapsed. The audit independently
rebuilds every final site row, all reviewed development site summaries, merged
development lineage and episode summaries, deferred-unit fields, names, scope
statuses, and action-specific linkage fields.
