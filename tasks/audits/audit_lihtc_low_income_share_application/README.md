# Audit low-income-share application

This independent audit reconstructs every applied low-income-unit value from
the two validated review ledgers. It verifies the exact 176 replacements, 11
affirmed nominal 20-percent set-asides, 88 unresolved exclusions, and 550
incomplete-count exclusions.

It also proves that development, financing-episode, and site keys and row
counts are unchanged; that original columns are immutable except for the
reviewed physical-development low-income value; and that raw episode counts
are never rewritten.
