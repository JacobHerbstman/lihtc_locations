# Prepare LIHTC Single-Address Review

This task prepares the remaining physical-development identity questions among
developments with exactly one standardized site key. It covers the 50 states
and the District of Columbia and excludes every address shared with a
multi-address development. It also defers obviously nonphysical, compound,
range, intersection, parcel, and multiple-address labels rather than treating
one source cell as proof of one physical address. Street-only keys without a
leading structure number and known portfolio/source cross-listings are also
deferred.

Previously reviewed distinct pairs remain visible as constraints, but fully
resolved address groups are not reopened. The task only prepares internal
evidence. It does not merge developments, edit addresses, call a geocoder, or
approve a query.

Run `make` from `code/`.
