# Research Understanding Checklist

- [x] The target unit is the physical development, above project episodes and
  development sites.
- [x] A common address can support one future coordinate query without proving
  that two records are the same physical development.
- [x] Distinct financing phases remain separate physical developments unless
  the evidence identifies duplicate reporting or paired financing for one
  buildout.
- [x] Every HUD row remains a project episode after an identity merge.
- [x] The outside read corroborates identity; it does not certify source
  address accuracy.
- [x] No round-two decision approves geocoding.
- [ ] Revisit compound addresses and ranges only after the round-two partition
  has been applied and the residual shared-address population has been audited.
