# Apply LIHTC Compound-Address Review

This task creates an address-component layer beneath the unchanged final source
site table. A source site normally maps to one inherited component. The 3,309
two-read split decisions map to their 9,091 explicit reviewed components. The
37 fractional civic addresses remain one component, and 1,768 unresolved
compound cells remain one blocked component.

An address component is a candidate locational representation, not a claim
that punctuation has identified a separate building or parcel. Every component
retains its source-site key and raw address fields. No component or geocoding
query is approved or transmitted here.
