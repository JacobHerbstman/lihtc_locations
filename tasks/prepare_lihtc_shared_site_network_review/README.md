# Prepare LIHTC Shared-Site Network Review

This task prepares connected review networks among final physical developments
that share one or more exact standardized site keys. It preserves complete
development, site, and episode context for every network member, makes no
identity or site decision, and does not approve a geocoding query.

The outputs separate network-level questions, development-level evidence,
exact site-key questions, shared-site membership evidence, all sites of each
network development, and all episodes of each network development. The
site-key grain permits large transitive networks to be adjudicated edge by
edge rather than forcing one component-wide decision. A later review must
adjudicate every network and every shared key before shared addresses can be
used for geocoding or analysis.

Run `make` from `code/`.
