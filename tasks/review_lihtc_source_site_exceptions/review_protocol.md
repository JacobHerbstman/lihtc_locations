# Source-Site Exception Review Protocol

## Scope

The review covers exactly 22 committed concern groups containing 57 current
development records, 68 episodes, and 869 current site assignments. The queue
comes from the prepared source-exception task; this review does not search for
new concern groups.

## Evidence reads

The internal read uses the raw multisite rows, raw BIN tokens, primary-address
episode records, names, state identifiers, timing, and the earlier committed
lineage. The outside read uses the direct public records retained in the
prepared evidence fields. A current source assignment is accepted only when
the internal and outside evidence support the same property.

The validator snapshots every group's prepared development, episode, site,
and disposition counts. It joins a committed action contract to the prepared
site dispositions. It does not rerun fuzzy matching or infer a new site from a
name.

## Operative site decisions

- Confirmed foreign assignments may be removed later.
- A redundant base address may be removed only when the detailed building or
  BIN assignments remain.
- A confirmed canonical assignment is retained.
- An unresolved assignment remains unchanged.
- A legitimate umbrella-financing assignment is retained as source evidence
  but cannot define a physical property before a reviewed episode-to-property
  bridge exists.
- Plaza's six assignments are retained. Its two current development records
  may later merge to one physical property while both financing episodes stay
  separate.

## Mechanic Mill transaction

Massachusetts Housing Partnership and City of Attleboro records identify the
Mechanic Mill redevelopment at 67 Mechanic Street in Attleboro. That address
is absent from the eight copied source assignments. The review therefore
freezes one replacement record and one transaction identifier. A later apply
task must validate and add the replacement in the same transaction that
removes all eight foreign assignments. Partial execution is prohibited. The
direct sources do not state a ZIP code, so the replacement ledger does not
assert one.

## Remaining blocks

The review leaves 22 Alaska parcel-description assignments unpartitioned, ten
HCCI placeholders without physical sites, and four Washington blank-BIN
primary rows pending campus confirmation. Wayne at Bicknell and Orient Heights
retain their confirmed current rows but remain incomplete site inventories.
No missing building is inferred.

All source rows and episodes remain available as evidence. Every repair is
`not_applied`, every source-change flag is false, and every geocoding query is
`not_approved`.
