# Census sources for metropolitan government fragmentation

This acquisition task preserves four public Census source files in `data_raw/census_governments/2026-09-15/`. The retrieval date is distinct from each source's reference period. Make displays every URL and destination explicitly and checks the recorded SHA-256 before publishing a download. A failed transfer or changed publisher file leaves the saved target untouched. Root Make reaches acquisition; unchanged builds reuse these files.

- [2022 Government Units Listing](https://www.census.gov/data/datasets/2022/econ/gus/public-use-files.html): `govt_units_2022.ZIP`, containing the final Excel inventory and its file-layout documentation. The analysis uses only the **General Purpose** sheet. Its 38,736 governments include 96 functionally dormant units; the primary measure excludes those and retains their count separately. This is an inventory of governments, not a list of zoning authorities.
- [March 2020 MSA delineations](https://www.census.gov/geographies/reference-files/time-series/demo/metro-micro/historical-delineation-files.html): `list1_2020.xls` gives county membership, and `list2_2020.xls` gives principal-city state/place codes. Use MSA boundaries, not metropolitan divisions, CSAs or New England city-and-town areas.
- [Vintage 2021 county population estimates](https://www2.census.gov/programs-surveys/popest/datasets/2020-2021/counties/totals/): `co-est2021-alldata.csv`, field `POPESTIMATE2021`. Sum disjoint member counties for the metro denominator. Selected central-city populations in the government inventory are also dated 2021.

The government-file documentation defines its county as the county primarily served or the headquarters county when the government crosses county lines. Thus the first analysis uses **Census primary-county assignment**, not a reconstructed jurisdiction footprint. It counts each government once and does not claim exhaustive membership for authorities spanning MSA boundaries. Mailing ZIP codes are not used. `IS_ACTIVE=N` means functionally dormant; the Census still includes those units in its official government count.

`report_sources.R` checks the saved bytes and writes `output/source_inventory.csv` plus its deterministic report. SHA-256 values in the Makefile and inventory refer to bytes retrieved September 15, 2026. These public source bytes may be redistributed. No credentials or API keys are required.
