# Apply LIHTC Mixed-Site Identity Review

This task applies the committed mixed-site member partition after the
source-site exception repair. It preserves every project episode, maps the 194
physical-source development records to 104 reviewed physical developments,
and rebuilds each physical development's union of source-repaired site keys.

The 340-unit Hobbs/Ciena financing umbrella remains as a flagged nonphysical
lineage row so its episode is not lost. The output also preserves the 12
nonphysical rows identified by the upstream source-site review. It therefore
contains 53,940 development-scope rows: 53,927 physical developments and 13
nonphysical rows. Downstream physical samples must exclude every scope status
beginning `nonphysical_` rather than treating every row as a physical
development.

The task does not sum source-reported units. Merged physical developments keep
their episodes, receive missing development-level unit totals, and remain in
the unit-scope review queue. No geocoding query is approved.
