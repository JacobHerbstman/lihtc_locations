# Prepare LIHTC Cross-Development Address Review Round 2

This task converts the remaining name/timing and phase/component pair strata
into connected identity questions. Reviewing connected components prevents one
development from receiving inconsistent decisions through different pairwise
edges.

The task only prepares evidence. It does not merge a development, edit a source
address, approve a query, or call a geocoder.

Run from `code/`:

```sh
make
```
