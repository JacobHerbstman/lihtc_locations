# Review Texas No-Site Source Candidates

This task records the second-read disposition of exactly 14 Texas no-site
candidates: 12 exact TDHCA name matches and two fuzzy name matches with exact
city and total units. It validates the frozen preparation outputs, the full
second-read manifest, and every byte used as source evidence. The 14-row
development ledger remains at one row per development. A 13-row evidence child
ledger binds each source-specific claim to its file, URL, retrieval date, hash,
and source type; Justice Park has two evidence rows because its disposition
uses both the 2012 and 2024 municipal records.

This is an evidence ledger, not a site-repair task. The six address-correlated
rows are candidates only: none is accepted, applied as a site, or approved as a
geocoding query. The six conflict/incomplete-scope rows and two unresolved
rows likewise create no site, address, query, or approval. Same-agency TDHCA
material is never treated as independent address corroboration.

Only 14 of 91 Texas no-site questions are covered here. The remaining 77 have
not received this second read. No result in this task may be generalized to
them.

Run `make` from `code/`.
