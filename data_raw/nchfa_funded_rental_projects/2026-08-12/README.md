# NCHFA Funded Rental Projects Directory Freeze

Retrieved 2026-08-12 from NCHFA's official **Find Awarded Projects** directory:

<https://housingbuildsnc.com/rental-housing-partners/rental-developers/find-awarded-projects>

NCHFA publishes the directory as 83 paginated HTML responses (`page=0` through
`page=82`). The response bytes are frozen in `pages/`;
`source_manifest.csv` lists each page URL, retrieval date, filename, byte
count, and SHA-256 digest. The 83 pages contain 1,653 displayed project rows.

NCHFA describes this directory as a list of apartment developments it has
financed. Its published columns are project name, city, county, total units,
type, target population, owner, contact, bond-deal indicator, and year. It
does not publish a street address, coordinates, or a stable project identifier
in this directory. Thus this raw source may support reproducible candidate
identity screening, but it does not establish a physical address, a complete
physical-site inventory, or any geocoding approval.
