# IHCDA existing LIHTC properties source-page freeze

This directory preserves the Indiana Housing and Community Development
Authority's official LIHTC landing page retrieved on 2026-08-12. The page
links an official workbook described as the listing of existing Low Income
Housing Tax Credit properties, updated 2026-05-11.

The workbook itself was not frozen in this snapshot. Accordingly, the source
page documents a currently unavailable screening source; it does not supply
property records, candidate identities, sites, addresses, or geocodes.
`source_manifest.csv` records the exact frozen page URL, byte count, and
SHA-256 digest.
