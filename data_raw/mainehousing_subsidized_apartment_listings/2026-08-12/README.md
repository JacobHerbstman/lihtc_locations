# MaineHousing Subsidized Apartment Listings snapshot

Retrieved 2026-08-12 from MaineHousing, Maine's housing finance agency. The
HTML source page links to one current subsidized-apartment-list PDF for each
of Maine's sixteen counties; the source manifest records every frozen byte,
its direct official URL, retrieval date, size, and SHA-256 hash.

The Somerset PDF was independently re-retrieved through its exact frozen
source-page URL. Its 231,244 bytes and SHA-256 matched the stored file.

The directory covers apartments developed with government financing, not a
LIHTC-only universe. It is preserved as first-source screening evidence, not
as an accepted replacement for a missing historical LIHTC site or address.
